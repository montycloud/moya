Open-source multi-agent framework

The multi-agent framework for Python.

MOYA is a model-agnostic framework for agentic AI. Compose agents, tools, memory, orchestration and delegation into systems you can read, test, and run on any model — from a single assistant to a coordinated team.

Get started → Star on GitHub
$ pip install "moya-ai[openai]"

Runs on OpenAI · Ollama · Bedrock · Azure — same code, any model.

team.py 
from moya import create_agent, Pipeline, AgentStep

# Two specialists, wired into one pipeline.
researcher = create_agent(
    "openai", name="researcher",
    description="Finds the facts")

writer = create_agent(
    "openai", name="writer",
    description="Explains them clearly")

team = Pipeline([
    AgentStep(researcher),
    AgentStep(writer),
])
print(team.run(thread_id="t1",
               message="Explain black holes"))
Model-agnostic

One API across OpenAI, Ollama, Bedrock, Azure and remote agents. Switch models without rewriting your logic — or run everything locally.

Multi-agent by design

Orchestrators, a delegation manager, and pipelines with parallel, loop and branch steps. Coordinate a team of specialists, not just one chatbot.

Batteries included

Tools, versioned skills, short- and long-term memory, MCP and A2A — the parts you'd otherwise wire by hand, ready to compose.

What's in the box

One framework, from a single agent to a team

Small, composable building blocks with a consistent API. Use one on its own, or wire several into a system.

Agents

LLM agents, one interface

Create an agent for any provider with a single factory. Give it a name, a persona, and — optionally — tools and memory.

  • OpenAI · Ollama · Bedrock · Azure · Remote
  • Streaming and non-streaming responses
agents.py
# Same call, different brains.
openai = create_agent("openai",  name="a", description="d")
local  = create_agent("ollama",  name="b", description="d",
                      model="llama3.1")
aws    = create_agent("bedrock", name="c", description="d")
Tools

Let agents call your code

A tool is just a Python function with a docstring. Register it and the agent can call it — MOYA builds the schema from your type hints automatically.

  • Plain Python functions or HTTP APIs
  • Auto-generated tool schemas
tools.py
from moya import ToolRegistry, Tool

def get_weather(city: str) -> str:
    "Return the current weather for a city."
    return "Sunny, 24C"

tools = ToolRegistry()
tools.register_tool(Tool(name="get_weather",
                         function=get_weather))
Memory

Agents that remember

Give an agent short-term working context, long-term recall on disk, or both — composed together. Memory is keyed by conversation thread.

  • Short-term windowed context
  • Long-term, searchable, persistent
memory.py
from moya.memory import (
    ShortTermMemory, LongTermMemory, CompositeMemory)

memory = CompositeMemory([
    LongTermMemory(base_path="./memory"),
    ShortTermMemory(window_size=10),
])
agent = create_agent("openai", name="a",
                     description="d", memory=memory)
Orchestration & Delegation

Coordinate a team of agents

Route work to the right specialist, or have a coordinator delegate tasks — sequentially or in parallel — and aggregate the results.

  • Simple, Multi-Agent and ReAct orchestrators
  • DelegationManager with depth limits & parallel dispatch
delegate.py
from moya.delegation.manager import DelegationManager

manager = DelegationManager(registry)
answer = manager.delegate(
    task="Where is order A1001?",
    agent_name="shipping_agent",
)
Pipelines

Multi-step flows

Chain agents into a pipeline with parallel branches, loops and conditional routing — the same primitives the visual Studio generates.

  • AgentStep · ParallelStep · LoopStep · BranchStep
pipeline.py
from moya import Pipeline, AgentStep

pipeline = Pipeline([
    AgentStep(researcher),
    AgentStep(writer),
])
result = pipeline.run(thread_id="t1",
                     message="Explain quantum computing")
Interoperability

MCP tools & agent-to-agent

Connect any Model Context Protocol server to give agents external tools, or call specialist agents running on other machines over the A2A protocol.

  • MCP over HTTP/SSE or subprocess
  • A2A remote agents as first-class participants
mcp.py
from moya.mcp import MCPClient

client = MCPClient.from_url("http://localhost:8080/sse",
                           name="search")
for tool in client.get_tools():
    tools.register_tool(tool)

Quickstart

From install to a running agent in minutes

Install MOYA

$pip install "moya-ai[openai]"

Write an agent with a tool

app.py
from moya import create_agent, ToolRegistry, Tool

def add(a: int, b: int) -> str:
    "Add two numbers."
    return str(a + b)

tools = ToolRegistry()
tools.register_tool(Tool(name="add", function=add))

agent = create_agent("openai", name="mathbot",
                     description="Does arithmetic",
                     tool_registry=tools)

print(agent.handle_message("What is 21 + 21?"))

Run it

$python app.py

No OpenAI key? Swap "openai" for "ollama" and run a local model.
