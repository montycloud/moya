# Architecture Decision Records — Moya Agent Studio

This directory contains Architecture Decision Records (ADRs) for the Moya Agent Studio project.
Each ADR documents a significant decision: the context that drove it, what was decided, and the consequences.

ADRs are immutable once accepted. Superseded decisions get a new ADR; the old one is updated to point to it.

| [ADR-002](ADR-002-two-area-navigation.md) | Two-area navigation: Builder and Marketplace | Accepted |
| [ADR-003](ADR-003-frontend-stack.md) | Retain existing React + TypeScript + React Flow + Tailwind stack | Accepted |
